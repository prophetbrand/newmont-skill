# Smoke run of the new cases, 2026-11-16

Five new cases, one run each, against the template-routing skill (branch `feat/template-routing-oct2025-guidelines`). Each run was an Opus subagent given only the path to SKILL.md, the case prompt, a fresh scratch directory, `NEWMONT_BRAND_LOG` pointed at a file in that directory, and the rule "if the skill's process calls for asking the user something, write the questions to questions.md and stop; this is an unattended run". Graded by hand from each run's reply, output files, run record and log, with `check_deck.py` re-run on every deck. Outputs are in the session scratchpad (`scratchpad/evals/<case>/`).

Note: SKILL.md and the scripts were being edited while these cases were written and run (the router gained `performance`/`safety performance`/`results` cues; `Deck()` gained a keyword-only `activation_path`; the checker now exits 1 on FAIL; the Word section moved to p30 with a navy header band). Results describe the state at run time.

## What varied or was weak

- **QBR deck is three slides.** The run put figures, highlights and risks on one `Overall Highlights` slide. It is within that layout's limits and the graders allow it, but it skips `ScoreCard Tables` and `Highlights, Risks & Mitigations`. A repeat run could easily spread the same content over two or three content slides, so slide count is the first thing to check for variance.
- **QBR log has two lines for one request**, because the run saved the deck twice (see defect 3).
- **Ambiguous case took outcome (a)**, writing the question down and stopping, not (b), the unattended default. Both are allowed. SKILL.md allows both too ("If no one can answer (an unattended run…) it defaults to Executive Summary" vs "In an unattended run, write the questions down … and stop"), so a repeat run may flip between them.
- **Word memo** used page 31 of the guidelines, with a white page, the monogram top-left and a Montserrat 7 pt footer. The current SKILL.md, edited after the run, now specifies "a dark navy header band with the reversed logo left" (p30). A rerun should produce a different memo design. The run also left a `.venv` and extracted template folders in its output directory.
- Two runs reported that the call table in SKILL.md, as it stood during the run, did not match the kit: `activation_path` was shown as a positional argument, and `Title Sub and Content` has no `table1` role (the table goes in through `body`). The first point is fixed in the current SKILL.md.

## Defects believed to be in SKILL.md or the scripts

1. **Router keyword cues are fragile.** The cues are matched as bare words: `scripts/route_template.py` line 15 has `"performance", "safety performance", "results", "dashboard",`.
   - In a strategy deck, "publish the monitoring results" adds a Detailed View cue, and the router then asks instead of choosing Executive Summary. Reproduced: `route_template.py "Treat every discharge and publish the monitoring results. a deck explaining our water strategy"` asks.
   - A test disclaimer such as "not Newmont results" also counts as a cue.
   - The original financial prompt ("executvive summary slide template to show quartlery financials and reporting") still matches no cue, although SKILL.md routes "operational or financial performance and results" to Detailed View.
2. **Relative `NEWMONT_BRAND_SOURCES` / `NEWMONT_BRAND_LOG` resolve against the skill root, not the working directory.** In `scripts/brand_sources.py`: `absolute = lambda p: os.path.normpath(os.path.join(base, os.path.expanduser(p)))`, where `base` is the config directory. `./empty-sources` became `/Users/bpatel/dev/newmont-skill/empty-sources`. SKILL.md does not mention this, and a relative log path would write into the repo.
3. **Every `Deck.save()` appends a log line.** SKILL.md says "`d.save(path)` | writes the deck, the run record `<path>.run.json`, and the request log line". A run that saves, looks at the render, fixes and saves again logs one request twice. The log should be written once per request, or the second save should replace the first entry.
4. **The unattended rules contradict each other**, as described under "What varied". Phase 3 says an unattended run defaults to Executive Summary. "How to ask" says an unattended run writes the questions down and stops. SKILL.md should say which of these wins for the template question.
5. **No logo source for non-PowerPoint formats.** "Other formats" asks for "logo top-left of the first page" / "the logo top-left or top-right" but no source file provides a logo. The memo run pulled `image2.emf` from the template master, and that image has a clipped trademark symbol.
6. **Fixed during the run window, now consistent:** `check_deck.py` exited 0 when checks failed (it now exits 1), and SKILL.md listed `activation_path` as a positional argument (it is now keyword-only, matching the kit). The programmatic grader `14-checker-clean` greps for FAIL lines, so it works with either behaviour.
