# Copilot Studio test, 17 November 2026

Platform: https://copilotstudio.microsoft.com, Prophet, Inc. default environment, the new credit-powered **Agent** type (not the Standard rule-based agent). Driven with Playwright in a persistent Chromium profile (`tools/copilot-studio/`); the person signed in and passed MFA by hand, the rest was scripted. No agent was published; everything ran in the builder's Preview.

## What the builder offers

Build page: Instructions (rich editor, no character counter shown), Model (Auto), Channels, **Skills** (Upload a skill: SKILL.md or .zip with SKILL.md; Create from blank; Browse skills preview), **Tools** (Featured connectors such as SharePoint and OneDrive, MCP, Connectors, Workflows; no code-interpreter tool to add, code runs natively), **Knowledge** (Search all websites by default), Connected agents, Memory (preview). Review panel warns about no evaluation and no channel; neither blocks Preview.

## The size limit

A skill that starts a conversation in Preview must keep the whole agent definition under **20,000,000 characters of YAML**; the skill's files are embedded in it base64-style, so about **15 MB of zip members** is the practical cap. Observed:

| Package | Zip | Members | Result |
|---|---|---|---|
| full (both templates, 31.4 MB) | 31.4 MB | 44 MB | Preview 502 at conversation start, no message |
| Executive Summary only | 21.9 MB | 24 MB | same 502 |
| Detailed View slimmed (sample slides stripped) | 18.2 MB | 20.2 MB | explicit error: "BotDefinitionOverride YAML is 27,006,265 characters, maximum 20,000,000" |
| no templates | 8.8 MB | 10.7 MB | starts |
| **Detailed View derived + compressed PDF** | 10.0 MB | 10.9 MB | starts, builds |
| **Executive Summary derived + compressed PDF** | 11.7 MB | 12.7 MB | starts, builds |

Derived copies: the templates have their sample slides stripped (as before) and their three largest opaque PNG photos re-encoded as JPEG with the rels and content types rewritten (Detailed View 9.5 → 5.3 MB zip, Executive Summary 11.3 → 7.1 MB). The guidelines PDF has its images downsampled to 800 px JPEG and fonts subset (10.5 → 5.4 MB); text and layout intact, checked on page 23. One template per package; both together (18 MB members) would exceed the cap. Whether a *published* agent has the same cap is untested.

Later (18 November): stripping the hdphoto picture originals from the derived templates brings both templates to 3.5 MB each, and one package with both templates and the compressed PDF (12.6 MB of members) starts in Preview and builds. See RESULTS-2026-11-18-suite.md.
